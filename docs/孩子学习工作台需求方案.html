01项目概述

1.1 背景与目标

当前家庭学习场景中，作业与额外任务的布置、执行监督、用时记录、结果检查与奖励兑现高度依赖口头沟通与人工记忆，家长监督成本高，孩子缺乏自主管理反馈。本系统通过 PC（家长）与平板（孩子）双端协同，将上述闭环数字化。

核心目标：

  1. 把「布置—执行—计时—提交—检查—激励—统计」形成可追溯的数据闭环。
  2. 降低家长监督成本：任务一次布置，进度、用时、结果自动汇总。
  3. 培养孩子自主管理能力：孩子自主选择任务、自主计时、自主提交，即时获得积分与反馈。

1.3 术语约定

术语定义
任务家长下发的最小执行单元，含学校作业、朗读、阅读、复习、自定义五类。
预计时长家长设定的任务期望完成时间（分钟），用于到时响铃与准时率计算基准。
实际用时孩子从点击「开始」到「提交」之间系统记录的有效计时时长。
响铃提醒实际用时达到预计时长时，在孩子端触发的铃声/震动/视觉提醒。
检查与评价家长对孩子提交结果进行通过/驳回，并给出星级与评语的动作。
准时率在截止时间前提交且通过检查的任务占已完成任务的比率。
奖励家长可配置的激励项，如增加平板使用时间、去商场、去公园，以积分为兑换货币。
独占模式平板启动后仅允许运行本应用，系统级屏蔽切应用/Home/通知栏等出口；退出须家长授权。又称 Kiosk 模式。
家长解锁码家长设置的解锁密码，仅在家长 PC 端输入并校验，孩子端不保存、不校验。
解锁令牌家长验证通过后由服务端签发的一次性、短有效期凭证，孩子端凭此退出独占模式。
自由使用时长兑换「增加平板使用时间」类奖励后获得的额度，在额度内可离开学习应用；用尽自动回到独占模式。
受控白名单跳转在 Lock Task 白名单内，从学习工作台启动钉钉等已授权应用；仍处 Kiosk 锁定态，白名单外应用不可打开。
钉钉打卡任务学校要求在钉钉内完成的打卡类任务；系统负责跳转、限时、留痕与凭证确认，不代替孩子完成打卡。

1.6 设备侧实施基线（华为 Android 平板）

设备为 2022 年华为平板、早期 HarmonyOS 2.x（DEF-21），因此独占方案由"二选一"收敛为 Android 单一路径：设备所有者（Device Owner）+ 锁定任务模式（Lock Task Mode / 固定屏幕）。这是 Android 官方支持的专用设备能力，可持久生效、重启后保持，优于普通桌面锁、应用锁或无障碍服务。

关键区分：HarmonyOS 2.x 与 2024 年后的鸿蒙 NEXT 不是一回事。HarmonyOS 2.x 仍可安装和运行 Android APK，底层基于 AOSP，Android 企业 API（Device Owner / Lock Task Mode）原则上可用；只有鸿蒙 NEXT 才彻底不再兼容 APK、导致本方案失效。2022 年的设备属于前者，因此方案不变，只需按 1.6.1 自查确认。

1.6.1 设备自查流程（约 5 分钟）

  1. 确认系统版本：设置 → 关于平板 → 查看「型号」与「HarmonyOS 版本」。若显示 HarmonyOS 2.x 或 Android 10/11，继续后续步骤；若显示 HarmonyOS NEXT / 5.0 及以上且不兼容 APK，立即停止并升级方案。
  2. 开启开发者选项：在「关于平板」中连续点击「版本号」约 7–10 次，提示已进入开发者模式后，到「设置 → 系统和更新 → 开发人员选项」开启。
  3. 开启 ADB：在开发人员选项中打开「USB 调试」；若存在「仅充电模式下允许 ADB 调试」也一并打开。用 USB 连接电脑，平板弹出提示时选择「传输文件（MTP）」并授权本机调试。
  4. 关闭纯净模式：设置 → 系统和更新 → 纯净模式 → 关闭，否则后续侧载安装自研 App 可能被拦截。
  5. 电脑端执行自查命令：安装 platform-tools 后运行下列命令，把输出记录下来：
adb devices
adb shell getprop ro.product.model
adb shell getprop ro.build.version.release
adb shell getprop hw_sc.build.platform.version
adb shell dpm device-owner
  • adb devices 应显示设备为 device 而非 unauthorized；否则重新授权 USB 调试。
  • ro.build.version.release 若返回 10 / 11，说明底层 AOSP 版本可用；HarmonyOS 2.x 通常仍返回 Android 基线版本。
  • dpm device-owner 若提示无设备所有者，即可按 1.6.2 激活；若已存在其他 Device Owner（如厂商预置），须先恢复出厂设置。

此步骤只做只读查询，不改变设备状态，可在孩子当前平板上直接执行。

1.6.2 前提条件与激活路径

项目要求
系统版本Android 5.0（API 21）以上；Android 10 起强制要求应用为 Device Owner 或 Profile Owner 才能调用锁定任务。目标设备为 HarmonyOS 2.x（2022 年），兼容 Android APK、底层为 AOSP，原则上具备企业 API；是否实际可用以 1.6.1 自查结果为准，不得跳过验证直接假设。若自查发现为鸿蒙 NEXT，本方案不适用。
单台激活 推荐起步设备恢复出厂、不登录任何华为账号状态下，USB 连接电脑执行 adb shell dpm set-device-owner 包名/.DeviceAdminReceiver。设备一旦存在账号则命令失败，须先恢复出厂。此操作不可通过应用内普通权限撤销。
批量激活 P2通过 Android Enterprise 专用设备（Dedicated Device）二维码 / NFC 零触摸注册，配合 MDM 下发设备所有者策略。当前单台设备无需引入 MDM。
锁定白名单设备所有者应用调用 setLockTaskPackages() 将本应用加入白名单；应用启动后调用 startLockTask() 进入锁定，此后 Home / 最近任务 / 通知栏被系统隐藏；同时设置 DISALLOW_CREATE_WINDOWS 并关闭华为智慧多窗应用栏（见 1.6.3）。
开机自启应用注册 BOOT_COMPLETED 接收器，开机后自动启动主界面并调用 startLockTask()；配合 setKeyguardDisabled 禁用锁屏、setStatusBarDisabled 禁用状态栏；使用沉浸式全屏布局。

1.6.3 华为定制系统需额外处理的逃逸点

Android 原生 Lock Task 能拦截标准三键导航，但华为 HarmonyOS 2.x 的部分定制交互仍需单独验证与处理：

  • 手势导航：上滑回桌面、侧滑返回等手势在部分厂商系统上仍可能触发；须在设置中固定为三键导航或在应用中处理返回事件。
  • 物理/硬件按键：部分机型返回键、最近任务键可通过硬件或组合键触发；须真机逐一验证，配合设备所有者策略禁用状态栏与锁屏。
  • 智慧多窗 / 悬浮窗 / 分屏（重点）：华为平板支持从屏幕左右边缘滑出「多窗口应用栏」把 App 拖成悬浮窗、缩成迷你窗 / 悬浮球、从最近任务切换为小窗，部分机型还可把链接或附件以悬浮窗打开。这是系统级多任务能力，不因应用全屏而自动失效，也不受 Lock Task 白名单直接管辖；Android Kiosk 指南将「悬浮窗 / 画中画覆盖层」列为需专门测试的逃逸路径。必须在激活前关闭「智慧多窗应用栏」（设置 → 辅助功能 / 智慧多窗 → 关闭应用栏开关），由设备所有者设置 DISALLOW_CREATE_WINDOWS 禁止其他应用创建覆盖窗口，且不启用 LOCK_TASK_FEATURE_RECENT_APPS。逐项验证见下表。
  • 系统对话框与通知：Lock Task 下仍可能弹出系统对话框，须用 onUserLeaveHint 检测并立即重新调用 startLockTask()。
  • 应用内跳转：锁定期间禁止拉起浏览器、系统设置等外部 Activity，否则会中断锁定或抛 SecurityException。
多窗逃逸路径验证动作通过标准
边缘滑出多窗口应用栏在学习锁定态从屏幕左右边缘内滑并停留应用栏不出现；或出现但无法启动任何应用
最近任务 → 转小窗触发最近任务，尝试把应用卡片转为悬浮窗最近任务不可用，或转小窗操作无效
悬浮球切换应用尝试呼出悬浮球并切换到其他应用无悬浮球，或切换被白名单拦截
分屏手势把当前窗口拖向屏幕左右边缘触发分屏无法分屏；若分屏仍可触发，第二应用不得是白名单外应用
应用内链接 / 附件小窗在钉钉内点击链接或附件，观察是否以悬浮窗打开不得打开白名单外应用或浏览器；若系统强制打开须记录为已知限制并通知家长
结论：小窗能力由华为系统提供，学习 App 无法在自身界面内嵌入钉钉小窗，也不能把小窗当作产品功能依赖。它只能作为必须封死的逃逸面处理。上述五项任一项无法封堵，则 Kiosk 不合格：家长端防护等级标注为「软件级，不保证阻止切应用」，钉钉打卡按 1.8.1 路径 A（家长解锁）兜底，不得声称已实现受控独占。

1.6.4 与家长端的联动

  • 设备绑定：激活后生成设备标识（序列号 / 应用内生成的 deviceId），在家长端 P8 绑定孩子账号；一台平板绑定一个孩子，切换须家长解锁后在 PC 端操作（见边界 23）。
  • 解锁下发：家长验证通过后由服务端下发一次性令牌，App 内接收并校验后主动调用 stopLockTask() 退出锁定；ADB 不用于日常解锁，仅用于初始激活与故障恢复。
  • 状态回传：App 上报 isInLockTaskMode 实际状态而非仅上报应用状态；若检测到被意外移除 Device Owner 或锁定失效，立即向家长推送高危告警（见边界 24）。
  • 内置"健康使用平板 / 学生模式"定位：可作为辅助限制，但不能替代本方案——它由孩子端本地设置控制，不受家长解锁令牌约束，也不提供本需求所需的任务执行与审计能力。
实机验证清单（进入开发前必须完成）：① 目标机型与系统版本登记；② Device Owner 激活成功且 dpm device-owner 可查询；③ 开机后自动进入锁定态；④ Home/最近任务/通知栏/手势/分屏均无法逃逸；⑤ 家长令牌可解锁且仅一次有效；⑥ 物理电源键长按关机仍可用（安全出口）；⑦ 强制重启后自动回锁且令牌失效。任一项不通过，K7/K9 不得按 P0 真独占验收。

1.7 多孩子模型与数据隔离

系统按「家庭 → 孩子 → 任务执行实例」三层组织数据。一个家庭账号下可维护多个孩子档案；家长在 PC 端可切换查看任一孩子的任务、进度、统计与积分，孩子端仅能看到当前绑定孩子的任务。

对象规则
孩子档案每个孩子有唯一 ID、姓名、昵称、年级/年龄、头像、积分账户、设备绑定关系；档案可停用不可删除（保留历史数据）。
任务下发创建任务时须选择接收孩子：可单选、多选或全选。每个接收孩子生成独立执行实例（任务 ID + 孩子 ID 唯一），状态、计时、提交、评价、积分完全隔离。
多孩子看板家长端默认展示「全部孩子」汇总视图，可按孩子筛选切换；待检查、逾期计数按孩子分列；支持一眼看到谁未完成/谁超时。
设备绑定一台平板同一时刻只绑定一个孩子（主使用者）；切换孩子须家长解锁后在 PC 端操作，并记入审计。
数据隔离跨孩子数据严格隔离：孩子 A 无法看到孩子 B 的任务、提交、评价、积分与奖励；家长按孩子维度统计，汇总仅做加总，不混算。
批量与差异化支持一次布置给多个孩子（相同内容/时长/截止），也支持对单个孩子单独调整截止时间、奖励关联或追加备注。
默认口径：任务未显式选择孩子时不得默认全选，须家长明确指定，避免误布置给所有孩子（见 DEF-23）。

1.8 钉钉打卡受控跳转

部分学校要求在钉钉 App 内完成作业打卡。钉钉未开放第三方代打卡 API，因此不能在学习工作台内嵌页面直接完成打卡；而打卡必须打开钉钉，与独占模式（DEF-17）存在天然冲突。本节定义不脱离 Kiosk 管控前提下的实现方式。

1.8.1 三种路径对比

路径做法适用与代价
B 白名单受控跳转（推荐）将钉钉加入 Lock Task 白名单；孩子在任务内点「去钉钉打卡」直接启动钉钉，打卡后回到工作台，超时自动拉回。全程仍处于 Kiosk 锁定态，白名单外 App 不可打开。体验顺畅、管控不降级；代价是钉钉内聊天/班级群无法屏蔽，且需实机验证拍照/定位等打卡流程（见 1.8.3）。列为 P1，实机通过后按 P0 交付。
A 家长解锁兜底孩子申请 → 家长 PC 端输码 → 进入自由使用 → 打开钉钉打卡 → 交还回锁。零改造、最安全，但依赖家长在场，且自由使用期间所有 App 可用。作为 B 不可用时的兜底必须保留。
C 凭证确认（辅助）打卡在钉钉完成后，孩子回工作台上传打卡成功截图，家长在检查页核对并确认。系统无法验证打卡真伪（钉钉不开放结果查询），家长为最终判定人；截图仅作辅助证据，不单独作为通过依据。
明确不做：不采用模拟点击、无障碍自动化、外挂或钉钉账号共享等方式「代打卡」——既违反钉钉服务条款，也可能被学校判定为作弊。本系统只提供受控跳转 + 过程留痕 + 家长确认。

1.8.2 推荐实现要点（路径 B）

  1. 白名单收口：Lock Task 白名单固定为「学习工作台 + 钉钉」，新增任何第三方 App 须家长在 PC 端显式配置并重新做逃逸测试（DEF-25）。
  2. 任务类型：新增「钉钉打卡」类型（基础分见 DEF-01），创建时填写打卡要求、学校/班级来源、截止时间与凭证要求。
  3. 受控跳转：执行页提供「去钉钉打卡」按钮，通过显式 Intent 启动钉钉（包名以实机确认为准，常见为 com.alibaba.android.rimet）；跳转与返回事件记入审计。
  4. 回锁与限时：钉钉前台停留默认上限 10 分钟（DEF-24），到时自动把工作台拉回前台并提示；孩子也可按 Home / 返回键主动回到工作台。期间仍禁止打开白名单外应用。
  5. 提交与检查：回到工作台后点「我已打卡」提交，可附截图（P1）；家长检查页显示打卡时间与凭证并要求人工确认，通过后结算积分。
  6. 兜底切换：钉钉未安装、版本不兼容、打卡流程（拍照/选图/定位）在 Kiosk 下失败时，提示孩子改用路径 A，并通知家长。

1.8.3 必须实机验证的事项

验证项通过标准
钉钉启动后仍锁定钉钉在前台时，尝试打开微信/浏览器/系统设置均被阻止，无法退出 Kiosk。
打卡所需能力定位授权、相机拍照、相册选图、输入法在锁定态下可用；若相机/文件选择器被白名单拦截，须评估是否单独加入白名单并重做逃逸测试，不得整体放开系统应用。
返回路径Home / 返回键可回到学习工作台，且不退出 Kiosk；钉钉不会成为新的逃逸出口。
超时拉回超过 DEF-24 后自动拉回工作台并提示，事件记入审计。
账号边界孩子端使用学校钉钉账号；家长不共享账号。账号切换与退出登录不在本系统职责内，须由家长线下处理。
多窗 / 悬浮窗按 1.6.3 五项验证全部通过：钉钉始终全屏受控，不得被拉成悬浮窗或迷你窗，悬浮球不得切换应用；任一项失败即按路径 A 兜底。
边界声明：钉钉内可访问的聊天、班级群、小程序等内容不在本系统管控范围，本方案不承诺阻止孩子在钉钉内分心。若学校打卡频率高或钉钉内干扰严重，建议改用家长解锁兜底路径，或由家长在旁监督打卡。

04核心流程

4.1 双端协作主流程

4.2 关键子流程

流程 A：任务创建与下发

  1. 家长在任务中心选择任务类型：学校作业 / 朗读 / 阅读 / 复习 / 自定义。
  2. 填写标题、任务内容（朗读任务须填写全文文本）、预计时长、截止日期时间、关联奖励、备注。
  3. 选择保存为草稿或直接发布；草稿可编辑后择机发布。
  4. 发布后任务状态变为「待开始」，实时出现在孩子的待办列表中。
  5. 显式选择接收孩子（单选 / 多选 / 全选，未选择不得发布，见 DEF-23）。
  6. 任务指定多个孩子时，按孩子分别生成独立执行实例，状态、计时、提交、评价、积分互不串扰。

流程 B：任务执行与计时（孩子端核心）

  1. 孩子在待办列表自主选择任务，点击「开始」。
  2. 系统检查是否存在进行中的任务：若有，提示「请先完成/放弃当前任务」，保证单任务计时。
  3. 计时器启动，基于服务端时间戳记录开始时间，展示已用/预计时长与进度环；任务内容区展示要求与文本。
  4. 实际用时达到预计时长时触发响铃 + 震动 + 视觉弹窗，提供「继续做」「现在结束」「稍后提醒」（间隔与次数上限见 DEF-09）。
  5. 孩子填写结果（朗读遍数、阅读进度、复习掌握情况、备注、附件），点击「提交」。
  6. 系统记录实际用时、提交时间，状态变为「待检查」，并向家长推送待检查提醒。

流程 C：家长检查与评价

  1. 家长在进度看板的「待检查」分组打开任务，查看提交内容与附件、预计/实际用时对比、是否逾期。
  2. 家长选择「通过」或「驳回」。驳回须填写原因，任务回到「进行中」由孩子重做并重交。
  3. 通过后，家长给出 1–5 星与评语/标签，系统按积分规则结算积分并写入流水。
  4. 状态变为「已完成」，孩子端收到评价通知，可查看评语与所得积分。

流程 D：奖励兑换

  1. 孩子进入奖励商城，浏览家长配置的奖励及所需积分。
  2. 积分足够时发起兑换申请；不足时按钮禁用并提示还差多少分。
  3. 家长收到审批请求，选择通过或拒绝（拒绝须填写原因）。
  4. 通过：扣减积分、写入流水、生成履约记录；奖励类型为「增加平板使用时间」时，额外向绑定设备下发等额自由使用额度，须由家长验证解锁后生效（见流程 F）；拒绝：积分不变，通知孩子原因。

流程 E：逾期处理

  1. 系统按服务端时间定时扫描，到达截止时间仍未提交的任务标记为「逾期」。
  2. 双端收到逾期提醒；家长可选择：宽限（延长截止时间并通知）、取消任务、要求补做。
  3. 孩子仍可对逾期任务补做并提交，提交后状态为「待检查」，但标记「逾期完成」，不计入准时率。

流程 F：退出申请与家长解锁（独占模式核心）

  1. 孩子在平板端点击「交还平板 / 退出」，客户端不校验任何密码，仅向服务端提交退出申请，界面显示「已通知家长，请等待确认」。
  2. 家长 PC 端收到解锁请求通知（含设备、时间、孩子当前任务状态），进入「设备解锁」页。
  3. 家长输入 6 位解锁码（DEF-17）；服务端校验，连续错误达到 DEF-18 阈值则临时锁定并告警；校验通过后签发一次性令牌（DEF-19）。
  4. 服务端将令牌下发至绑定平板，孩子端校验令牌有效后立即退出独占模式；平板因网络离线无法接收时，令牌在有效期内重试投递，过期作废。
  5. 解锁结果分两种：存在自由使用额度则进入「自由使用模式」并启动倒计时；无额度则进入「家长临时解锁」，由家长设置时限或随时远程重新锁定。
  6. 家长拒绝时填写原因，孩子端保持独占并显示拒绝提示；全流程写入解锁审计（申请、审批人、结果、令牌有效期、设备标识）。

流程 H：多孩子任务下发与设备切换

  1. 家长在任务创建页选择接收孩子，可单选、多选或全选；未选择时「发布」按钮禁用并提示。
  2. 发布后服务端为每个接收孩子生成一条执行实例，各自独立进入状态流转。
  3. 家长在统一看板按孩子筛选查看各自进度；对个别孩子可单独调整截止时间、奖励或追加备注，调整仅作用于该孩子的实例。
  4. 平板默认绑定一个孩子。需换人使用时，孩子发起退出申请 → 家长 PC 端验证解锁 → 家长在 PC 端切换设备绑定 → 平板重新锁定并加载新孩子的待办列表。
  5. 切换后原孩子的进行中任务暂停并保留已用时长，新孩子从自己的待办开始；切换事件与解锁事件一并记入审计。

流程 I：钉钉打卡（受控跳转）

  1. 家长创建「钉钉打卡」任务，填写要求、截止与凭证要求，并显式选择接收孩子（DEF-23）。
  2. 孩子开始任务后点「去钉钉打卡」→ 系统校验白名单后将钉钉置前，记录跳转时间。
  3. 孩子在钉钉内完成学校要求的打卡；白名单外的 App 与链接被系统阻止。
  4. 打卡后按 Home / 返回键回到工作台，或超过 DEF-24 由系统自动拉回并提示。
  5. 孩子点「我已打卡」提交（可附截图），计时按服务端时间记录；家长在检查页核对凭证并人工确认，通过后结算积分。
  6. 任一环节失败（未安装、打卡能力受限、无法返回）→ 提示孩子发起家长解锁申请，走流程 F 兜底，并通知家长。

流程 G：自由使用额度到期回锁

  1. 进入自由使用模式时启动服务端倒计时，设备端仅展示剩余时长。
  2. 到期前 5 分钟（DEF-20）推送提醒；家长可提前远程锁定。
  3. 额度用尽，设备自动回到独占模式；若有未完成任务，其计时暂停并保留已用时长，回到学习模式后可继续。
  4. 回锁事件与额度消耗记入审计和积分/奖励履约记录，防止重复套取时长。

06任务状态流转

任务全生命周期共 9 个状态。状态机是计时、提醒、统计与积分结算的共同基础，所有模块须以状态为准，不得用布尔标志旁路。

状态进入条件允许操作
草稿家长创建未发布家长编辑、发布、删除
待开始家长发布；驳回后重交前孩子查看、开始；家长撤回/编辑（二次确认）
进行中孩子点击开始；驳回重做孩子计时、暂停/继续、提交；家长查看进度
待检查孩子提交；逾期补交家长通过/驳回；孩子在检查前可撤回重交
已完成家长检查通过只读；积分已结算；可查看评价
逾期到达截止时间仍未提交孩子补做提交；家长宽限/取消/要求补做
已取消家长主动取消或撤回只读；不计入统计分母
规则约束：状态流转由服务端统一校验，禁止前端直接改写。只有「待检查 → 已完成」触发积分结算，驳回不结算、撤回不重复结算。

自由使用时长 P1Σ 周期内实际消耗的自由使用额度（分钟）与奖励履约记录对账，防止额度超发。
异常尝试次数 P1密码连续错误、令牌过期、强制重启次数设备侧安全事件统计，异常升高时提醒家长检查设备。

09边界情况

#场景处理策略
1跨午夜/跨天任务截止时间按本地时区记录；计时跨午夜时，实际用时整体计入「开始日」的统计，任务列表在次日仍显示直至完成；统计口径在报表中注明。
2平板设备时间不准所有时间与计时以服务端时间为准；孩子端启动时校验本地与服务端时间差并展示校正后时间，差异超过阈值提示家长检查设备。
3平板离线 / 网络抖动待办列表与计时状态本地缓存；离线期间可继续计时与填写结果，恢复网络后自动同步。冲突时以服务端状态为准并提示孩子。
4切后台 / 锁屏 / 杀进程计时基于「开始时间戳 + 累计暂停时长」计算，不依赖 UI 定时器；进程恢复后按服务端时间重算并校正显示。
5重复提交 / 重复点击提交接口幂等（以任务执行实例 ID + 提交序号去重）；重复提交提示已提交，不产生第二条流水。
6执行中家长修改任务修改预计时长或内容须二次确认，并向孩子端推送变更通知；已产生的用时记录保留，预计时长变更影响后续响铃与统计。
7多孩子 / 多任务实例任务须显式指定接收孩子（DEF-23），按孩子分别生成执行实例；进度、用时、积分、评价、奖励与统计严格隔离；家长汇总仅做加总，不混算。
8逾期任务处理逾期不自动删除或关闭；孩子可补做提交，标记「逾期完成」，计入完成率但不计入准时率；家长可宽限、取消或要求补做。
9响铃被静音 / 免打扰铃声之外提供震动与全屏视觉提醒兜底；提示孩子端关闭系统免打扰；同一任务提醒次数上限可配置。
10积分不足 / 兑换被拒不足时兑换按钮禁用并提示差额；被拒时积分不扣减、冻结释放，向孩子展示拒绝原因。
11朗读录音 P2录音默认关闭，开启需家长授权；涉及未成年人语音，须明确本地存储范围、保留期限与删除入口。
12并发评价多家长同时评价同一任务时，服务端加锁；后写覆盖并保留双方历史记录，避免积分重复结算。
13任务被删除原则上不允许删除已有执行记录的任务；仅允许「取消」并保留快照，以保证统计与积分流水可追溯。
14时区与夏令时统一使用用户所在本地时区；截止时间保存为带时区时间戳，避免 DST 切换导致偏差。
15孩子暴力尝试解锁解锁码只在家长 PC 端/服务端校验，孩子端不保存也不校验；连续输错达 DEF-18 阈值后锁定 15 分钟并通知家长；计数与锁定状态存于服务端，孩子端重置无效。
16家长忘记解锁码家长通过 PC 端账号二次验证（密码/邮箱/预留问题）重置，重置操作记入审计并通知其绑定邮箱；孩子端无重置入口。
17网络离线无法解锁孩子端不提供任何本地绕过路径，显示「无法联系家长，请保持联网」；家长端恢复网络后可远程解锁。建议提供家长预生成的一次性应急码 P2，仅限断网时使用且用后作废。
18华为平板 Device Owner 不可用纯 Web 无法阻止切应用；2022 年 HarmonyOS 2.x 若实机自查发现 Device Owner 激活失败，降级为软件级锁定，家长端明确标注「软件级，不保证阻止切应用」，不得承诺完全防逃逸。若设备实为鸿蒙 NEXT（不兼容 APK），原生 App 方案整体失效，须重新评估设备。华为自带「健康使用平板 / 学生模式」不作为替代方案。
19系统手势 / Home / 通知栏 / 关机由系统级 Kiosk 策略屏蔽；必须保留至少一个物理紧急出口（如长按电源键关机）以保障人身安全，强制关机/重启事件上报家长并记入审计。
20设备重启 / 应用被杀配置开机自启，重启后自动回到学习锁定态；未消费的解锁令牌立即失效；重启事件与时长消耗上报家长。
21自由使用额度到期到期前 5 分钟提醒；到期自动回锁；进行中任务暂停计时并保留已用时长，回到学习模式后可继续；不产生逾期判定。
22奖励与独占冲突兑换「增加平板使用时间」仅获得额度，不等于解锁；须家长验证后生效，额度用尽自动回锁。孩子端不得显示「兑换后立即解锁」的误导文案。
23多孩子共用一台平板一台设备同一时刻仅绑定一个孩子；切换须家长解锁后在 PC 端操作并记入审计；原孩子进行中任务暂停并保留已用时长，新孩子加载自己的待办；切换过程不得泄露另一孩子的任务、评价或积分。
24ROOT / 越狱检测 P2检测到设备被 ROOT/越狱或 Kiosk 策略失效时，立即上报家长并尝试自动重新锁定；无法重新锁定时向家长推送高危告警。
32华为智慧多窗绕过小窗 / 悬浮窗 / 迷你窗 / 悬浮球 / 分屏属系统级能力，全屏与应用内锁定均不自动阻止。激活前关闭智慧多窗应用栏并设置 DISALLOW_CREATE_WINDOWS；实机验证 1.6.3 五项，任一项能打开白名单外应用即判定 Kiosk 不合格，不得按 P0 交付，钉钉打卡改走家长解锁兜底。
25多孩子数据串扰所有查询接口强制带孩子 ID 过滤；家长按孩子维度统计，孩子端只返回当前绑定孩子数据；跨孩子访问请求一律拒绝并记录安全事件。
26任务未选接收人未显式选择孩子时禁止发布（DEF-23），防止误布置给全部孩子；草稿可保存但不得下发。
27钉钉未安装 / 打卡失败点击跳转前检测钉钉是否安装并可启动；不可用、打卡能力（拍照/选图/定位）受限或无法返回时，提示孩子发起家长解锁申请走流程 F 兜底，并通知家长；不静默失败、不判定为逾期。
28钉钉内系统能力被拦截相机/文件选择器若不在白名单会导致钉钉打卡流程失败；须在实机验证后决定是否单独加入白名单并重做逃逸测试，禁止为图方便整体放开系统应用。
29孩子在钉钉内逗留超时超过 DEF-24 自动拉回工作台并提示，跳转与拉回事件记入审计；停留时长不计入学习时长，避免激励扭曲。
30打卡结果无法核验系统不自动判定打卡真伪，截图仅作辅助证据；须家长在检查页人工确认后才结算积分。不得用模拟点击/外挂/共享账号代打卡。
31钉钉内聊天与班级群分心不在本系统管控范围，产品不得承诺阻止；家长可在打卡任务备注中限定「仅完成打卡后返回」，如干扰严重改用家长解锁兜底并现场监督。

10验收标准

10.1 功能验收清单

家长端

  • 可创建五类任务并填写标题、内容、预计时长、截止时间、奖励关联；朗读任务可填写全文文本。
  • 草稿可保存并择机发布；发布后孩子端在 3 秒内可见；待开始任务可撤回修改。
  • 进度看板按 5 种状态分组，显示状态、预计/实际用时、是否逾期。
  • 可打开待检查任务查看提交结果与附件，执行通过/驳回（驳回须填原因）。
  • 通过后给出 1–5 星与评语，积分按规则结算并写入流水；重复点击不重复结算。
  • 统计报表可按日/周/月查看完成率、准时率、累计时长、类型分布，并可导出。
  • 可配置积分规则、星级阈值、奖励目录；可审批兑换，通过扣积分、拒绝不扣分。
  • 可开启/关闭独占模式、设置与重置解锁码、配置错误锁定与令牌策略。
  • 可接收孩子退出申请并在 PC 端输入解锁码审批；通过后签发一次性令牌，拒绝须填原因。
  • 可发放自由使用额度、远程锁定/解锁，并可查看解锁审计与异常尝试记录。
  • 可配置 Lock Task 白名单（默认仅工作台 + 钉钉），新增应用须二次确认并重做逃逸测试；可查看打卡跳转审计。
  • 可查看钉钉打卡时间与截图凭证，人工确认后才通过并结算积分。

孩子端（含独占模式）

  • 待办列表按今日/逾期/未来分组，显示类型、截止倒计时、预计时长、关联奖励。
  • 可自主选择任务并开始；已有进行中任务时阻止开启第二个并提示。
  • 计时准确展示已用/预计时长；切后台、锁屏后计时不中断。
  • 达到预计时长时触发响铃 + 震动 + 视觉提醒，三种操作（继续/结束/稍后）均可用。
  • 朗读任务展示全文文本，可调节字号；可记录朗读遍数、自评并标记完成。
  • 可填写反馈、上传附件并提交；检查前可撤回重新提交。
  • 可查看积分、星级、连续天数、积分流水、家长评价；可发起兑换并查看审批状态。
  • 启动后自动进入独占锁定态，系统 Home / 最近任务 / 通知栏 / 切应用出口不可用。
  • 点击退出仅能发起申请并显示等待状态；端内不存在密码输入框、设置入口或任何直接退出路径。
  • 仅在收到有效一次性令牌时退出独占；令牌过期、被拒绝或无网络时保持锁定。
  • 自由使用额度内显示倒计时，到期前 5 分钟提醒，到期自动回锁且未完成任务计时暂停并保留已用时长。
  • 钉钉打卡任务可受控跳转钉钉，手动或超时返回工作台；白名单外应用不可打开；失败时可发起家长解锁申请。

10.3 数据准确性验收

  • 完成率、准时率、累计学习时长在概览卡片、趋势图、导出文件中数值一致。
  • 统计分母自动排除已取消与未到期任务，周期边界按本地时区计算。
  • 积分流水与账户余额严格对账：收入 − 支出 = 当前余额。
  • 所有状态变更、评价修改、积分手工调整均有可追溯日志（操作人、时间、前后值）。
  • 解锁审计与设备事件日志完整：申请、审批人、结果、令牌有效期、强制重启均留痕。
  • 自由使用额度发放与消耗逐笔对账：发放总额 − 已消耗 − 剩余 = 0，且与奖励履约记录一致。

10.4 体验与性能验收

  • 计时显示误差 ≤ 1 秒 / 分钟；锁屏 30 分钟后恢复，累计用时误差 ≤ 5 秒。
  • 家长发布任务到孩子端可见延迟 ≤ 3 秒；孩子提交到家长待检查列表可见延迟 ≤ 3 秒。
  • 孩子端平板连续操作 30 分钟无卡死；触控目标 ≥ 44×44px；核心操作单步可达。
  • 多孩子、多任务并行场景下，进度、积分、评价、奖励与统计数据互不串扰。
  • 任务未选择接收孩子时发布按钮禁用；选择多个孩子后各生成独立实例且互不可见。
  • 切换设备绑定后，平板仅显示新孩子的任务，原孩子数据不出现在任何孩子端页面。
  • PC 端主流浏览器（Chrome / Edge）与平板主流浏览器兼容；关键页面支持 1280px 及以上分辨率。
  • 目标华为平板已完成 Device Owner 激活，isDeviceOwnerApp 与 isInLockTaskMode 均为 true；1.6 实机验证清单 7 项全部通过。
  • 设备关机/重启后 30 秒内自动回到学习锁定态；令牌过期后无法解锁。
  • 家长审批通过到平板实际解锁 ≤ 5 秒（在线状态）；远程锁定指令到设备回锁 ≤ 5 秒。
  • 强制重启 / Kiosk 策略失效事件上报家长延迟 ≤ 1 分钟。
